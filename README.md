# 我的小世界 🌙

一个暗黑魔幻风格的个人网站，藏在深夜尽头的秘密馆。

## 功能
- 🔐 **密码入口**：打字机效果欢迎语，输入密语方可进入（密码：`111913`）
- 🎴 **角色收藏馆**：L、塔矢亮、竹早静弥、四月一日君寻、壹原侑子，各有专属配色卡片
- 📓 **秘密日记**：机密档案风格，按日期封存，localStorage 持久化
- ✨ **我喜欢的**：音乐 / 影视 / 东西，可添加删除
- 🍓 **今日心情**：草莓评分（1-5 颗）+ 每日记录与心情轨迹
- 📜 **关于这里**：神秘的个人介绍

所有数据保存在浏览器 localStorage 中，移动端自适应。

## 添加角色图片
把图片放入 `images/` 文件夹，命名见 [`images/README.md`](images/README.md)。
缺图时会自动显示符文占位，不影响使用。

## 本地预览
直接用浏览器打开 `index.html` 即可。

## 部署
推送到 `claude/keen-allen-ogexto` 分支后，GitHub Actions 会自动部署到 GitHub Pages。
